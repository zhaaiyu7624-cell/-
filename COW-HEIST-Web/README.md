# COW HEIST 2.3 / 星际偷牛计划（网页 3D 版）

## Windows 直接试玩

完整解压网页 ZIP。已安装 Python 3.12 时，双击 `start-browser-windows.cmd`，脚本会以浏览器打开本地游戏。保持启动窗口开启。如果默认浏览器不合适，把窗口中显示的地址复制到 Chrome 或 Edge。默认端口为 4173，被占用时脚本会使用空闲端口。生产发行包附带 `dist/`、本地模型、WASM 和字体。试玩不需要安装 Node.js 或连接外部资源。

## 源码开发

技术栈为 Vite、TypeScript、Three.js、MediaPipe Hand Landmarker。使用 Node.js 22.12+ 或 24 LTS，在本目录执行：

```powershell
npm ci
npm run dev
```

Vite 默认地址为 `http://localhost:5173/`。执行 `npm run build` 构建，再用 `npm run preview` 或 `py -3.12 scripts/serve-build.py` 试玩生产版本。部署到静态站点时上传完整 `dist/`，摄像头需要 localhost 或 HTTPS。

## 玩法

开始偷牛 → 选择鼠标或手势 → 选择已解锁关卡。鼠标移到目标脚下，按住左键或空格；手势模式下，将一只手放入画面完成校准，移动手掌并捏住拇指与食指。点击「启用摄像头」才申请权限，切换鼠标或离开手势流程会释放媒体流。画面和推理结果在本机处理。

黑白牛连续受到牵引 1.35 秒得 100 分，黄牛 2.70 秒得 200 分。奶牛锁定后减速，进度到 35% 开始漂浮并逐渐向光束中心靠拢。短暂脱靶时先冻结 0.6 秒，之后按该牛种正常增长速度的 30% 回退。吸完危险南瓜、稻草人和废弃油桶分别扣 80、100 和 120 分，最低为 0 分。每关倒计时 3 秒后开始 60 秒挑战，时间到再结算。按 P 暂停。

| 关卡 | 目标 | 黑白牛 | 黄牛 | 障碍上限 | 障碍补充间隔 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 牧场试飞 | 1000 | 4 | 1 | 1 | 12 秒 |
| 午夜追踪 | 2000 | 5 | 1 | 3 | 8 秒 |
| 幽灵牧场 | 3200 | 6 | 2 | 4 | 6 秒 |
| 星际围捕 | 4500 | 7 | 2 | 5 | 4.5 秒 |

障碍物出现前有 1.1 秒橙色环预警。飞船停在预警点附近会推迟出现。在第二关起，部分障碍物缓慢移动，并可能生成在奶牛附近。奶牛吸完后等待 4.2 秒再尝试在空位补充。

连捕第 3–4 只触发 COMBO x2（每次额外 30 分），第 5 只起触发 COMBO x3（每次额外 45 分，上限）。连击仅放大额外奖励；误吸障碍物或 6.5 秒未捕获奶牛会清零。暂停不消耗连击时间。

通关解锁下一关。每关最高分与解锁状态由当前浏览器在同一地址下本地保存。清除站点数据会重置进度。

## 结构

- `src/levels.json` 集中保存四关目标、移动速度、吸取判定、障碍物和连击参数。
- `src/game.ts` 统一游戏循环、捕获和补充目标。
- `src/main.ts` 菜单、两种输入适配、HUD 与结算。
- `src/hand.ts` 本地手势识别、标定和摄像头生命周期。
- `src/world.ts` 与 `src/models.ts` 夜间农场和程序化场景模型。
- `scripts/serve-build.py` 生产网页本地启动。课程要求的 Python 游戏实现位于单独的 `COW-HEIST-Python` 提交包中。

## 2.2 原创音频

首次点击页面或按键后解锁声音。右上角扬声器按钮展开总音量、背景音乐、游戏音效与静音设置，设置按当前浏览器地址保留。所有音频从本地 WAV 加载，不需要网络音源。Windows ZIP 的 Python 启动脚本直接播放随包附带的 WAV。部署到静态站点前执行 `npm run build`，将 WAV 一并写入 `dist/audio/`。

## 2.3 捕获手感

未锁定的奶牛保留原有游荡速度和随机转向。四关的锁定速度依次为当前正常速度的 35%、40%、45%、50%，进度到 35% 后依次降至 10%、15%、20%、25%。奶牛起锁及维持半径扩大 18%，判定使用地面位置，模型的挣扎动画不影响锁定。障碍物保留原本判定及扣分机制。

两种输入共用牵引判定。鼠标小幅位移采用柔和跟随。手势位置按移动幅度调整平滑，捏合采用双阈值和不同的按下、松开确认时间。丢失手部时关闭光束。
