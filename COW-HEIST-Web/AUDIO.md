# COW HEIST 2.2 原创音频

声音来自 Python 数值合成。项目没有引入外部音乐、音效包或采样。五首曲目和十五个独立音效均是 44,100 Hz、16-bit PCM、立体声 WAV。

## 编曲

共同动机以 D 为起点，包含三全音、降三度和半音回绕。主菜单用稀疏 FM 八音盒、机械声和低频漂移；第一关用 78 BPM 的暗节拍引入机械脉冲；第二关 96 BPM 加入切分和更强低频；第三关 116 BPM 增加噪声、碎片动机和失真；第四关 136 BPM 使用更密打击、分段增强的警报、跳变电子信号。各段合成独立低频、和声、旋律、电子打击、噪声纹理与空间回响声部。

持续声部按整周期闭合，尾音与延迟跨循环边界回卷。循环文件以约 2 毫秒余弦衔接校正首尾采样。网页使用循环 AudioBuffer 播放；曲目切换交叉淡化约 1.15 秒。暂停降低背景音量并停止光束与吸取声，恢复继续同一轨道。

## 重新生成

在项目根目录执行：

```powershell
py -3.12 -m pip install numpy==1.26.4 scipy==1.17.1
py -3.12 scripts/generate_audio.py
```

输出到 `public/audio/bgm` 和 `public/audio/sfx`。打包网页前运行 `npm run build`。右上角声音设置支持总音量、背景音乐、音效和静音，状态按浏览器地址保存。
